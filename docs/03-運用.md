# 運用

引き継いだ人が最初に困るところを集めました。

## 稼働時間

費用を抑えるため、**動いている時間を絞っています**（`cdk/lib/constructs/cost-schedule.ts`）。

| 対象 | 仕組み |
|---|---|
| NAT インスタンス | 時間帯で起動・停止 |
| Aurora Serverless v2 | 最小容量を 0 にして休ませる |
| 画面 | CloudFront Function が時間外に **503 の案内ページ**を返す |

### 時間外に見えないのは仕様です

画面が「ただいま停止中」と出るのは、**閉じているから**です。確認したいときは
`?open=1` を付けるとクッキーが発行され、以後は素通しできます
（12時間有効。目隠しであって、閉じる仕組みではありません）。

### 時間外は API も 401 になります

NAT が止まると、API Lambda が Cognito の鍵取得に**到達できず5秒でタイムアウト**し、
**すべてのリクエストが 401** になります。「トークンが無効」と出ますが、
**認証の問題ではありません**。まず NAT の状態と経路（blackhole になっていないか）を
確認してください。

```
aws ec2 describe-instances --instance-ids <NATのID> --query 'Reservations[].Instances[].State.Name'
aws ec2 describe-route-tables --query "RouteTables[].Routes[?DestinationCidrBlock=='0.0.0.0/0'].State"
```

## デプロイ

```
./deploy.sh
```

### 終了コードを必ず確認してください

`cdk deploy` は**イメージのビルドに失敗しても 0 を返すこと**があります。
ログの失敗行（`Failed to build` / `failed to solve` / `ROLLBACK`）も併せて
確認してください。

### ディスクの空きを確認してください

Docker のビルドキャッシュが膨らみ、**容量不足でデプロイが失敗**します。
1晩に5回デプロイしてキャッシュが 21GB まで膨らんだ実績があります。

```
df -h /System/Volumes/Data
docker system df
docker builder prune -af    # 必要なら
```

## 落とし穴

### 照合順序は黙って戻ることがあります

日本語の検索のため、検索に使う6カラムを `utf8mb4_0900_as_ci` にしています。
**列だけ変えると、将来 `COLLATE` を省いた `MODIFY` が走ったときに表の既定へ戻ります**
（実測で確認済み）。そのため**表の既定も同じ照合順序**にしてあります。

なお **ID の列は `utf8mb4_unicode_ci` のまま**です。外部キーは参照先と同じ並びで
ないと張れないので、新しい表を作るときは揃えてください。

### 検索は索引が効きません

`LIKE '%語%'` は前方一致でないため、**どんな索引も使えません**。件数が増えたら
MySQL の `ngram` 全文検索を検討してください（DB を替える必要はありません）。

### 一覧の並べ替えは許可列で縛っています

画面に並べ替えのボタンがあっても、サーバの許可列に無いと**既定の並びに落ちます**。
実際にそうなっていた列がありました。突き合わせるテストを置いてあります
（`backend/src/api/features/review/routes/__tests__/sortable-fields.test.ts`）。

### 読み取り Lambda に積むものは限られます

`Dockerfile.document-reader` は必要なものだけを積みます。**`strands` を読み込む
モジュールは積めません**（起動できなくなります）。import を足したときに積み忘れると
Lambda が起動せず、**審査が必ず失敗します**。検査するテストを置いてあります
（`review-item-processor/tests/test_document_reader_packaging.py`）。

## 検証用の道具

実環境に対して流せる確認スクリプトが `scratchpad`（セッションごとの一時領域）に
ありましたが、**恒久的な置き場所はまだありません**。必要なら `scripts/` 等へ
移してください。
